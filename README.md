## 🌟 About The Project

This portfolio showcases my **projects, skills, and experience** in a clean, interactive, and animated way.
Built with a strong focus on **performance, responsiveness, and smooth user experience**, featuring glowing UI accents, animated skill meters, and interactive project cards.

---

## 🌍 Live Link

👉 https://mahamuda-afroz-portfolio.vercel.app/

---

## ✨ Features

* ⚡ Fast, responsive design with smooth entrance & hover animations
* 🎨 Clean, modern glassmorphism-inspired UI
* 📱 Fully mobile-friendly layout
* 🧩 Component-based, reusable architecture
* 📊 Animated skill progress indicators
* 📂 Interactive projects showcase with live demo & GitHub links
* 🏆 Certificates section with modal preview
* 📬 Contact section

---

## 🛠️ Tech Stack

* **Next.js**
* **TypeScript**
* **Tailwind CSS**
* **Framer Motion** (animations)
* **Lucide React** (icons)
* **Git & GitHub**
